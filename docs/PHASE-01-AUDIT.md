## Existing Problems / Inconsistencies

1. **No public website** — `website/` has image assets but no `index.html`, CSS, or JS
2. **Registry is default boilerplate** — still shows "Create Next App" placeholder content
3. **Registry metadata** — title is "Create Next App", description is "Generated by create next app"
4. **Empty directories** — `database/`, `website/css/`, `website/js/` are empty placeholders
5. **No `.env.example`** — no environment variable documentation
6. **No architecture documentation** — database plan, offline plan, responsive/animation docs missing
7. **Image filenames** — contain spaces (e.g., "tourism 1.jfif"), which can cause URL encoding issues
8. **No `index.html`** in website root — website is not functional
9. **Registry README** — default create-next-app README, not project-specific
